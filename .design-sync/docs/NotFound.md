The shared 404 page: green negative monogram (solid deep-forest lockup, H knocked out), wheat code chip, uppercase display headline, gray lede, and a green home Button. Props: code (default 404), title, description, homeHref/homeLabel (set homeHref null to drop the default anchor), actions (slot for framework links, e.g. Button asChild around next/link). No ember, no red — a missing page is wayfinding, not a failure. Demo in CataloguePatterns.
