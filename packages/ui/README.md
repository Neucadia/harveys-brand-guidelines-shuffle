# @harveys/ui

The Harvey's kit — 45 primitives in `src/`, styled exclusively with the
semantic `hb-*` utilities from `@harveys/tokens`' Tailwind preset (never the
brand repo's private scale, per `tokens.md`). This directory is the **source
of truth**; `src/components/ui/` in the repo root is a generated byte-copy
maintained by `scripts/sync-ui.mjs` so the CRA showcase compiles it. Edit
here, then run `node scripts/sync-ui.mjs`.

## Consuming a component (vendor, don't install)

1. Vendor `packages/tokens/dist/tailwind-preset.cjs` and add it to your
   `tailwind.config` `presets`; optionally vendor `tokens.css` and import it
   so the `--hb-*` layer exists (without it, the baked hex fallbacks render
   the identical values).
2. Vendor the component file(s) plus `utils.js` (`cn`) via
   `scripts/brand-sync.mjs` (see `packages/sync/README.md`) so the source
   commit and hashes are recorded.
3. Install the component's radix/cva peer deps at the pinned majors listed
   in `package.json`.
4. `tailwindcss-animate` is required for overlay/accordion animations.

House rules travel with the code: flat and square, Sonner-only toasts,
ember-never-red, `StatusChip` for table-scale statuses (solid `Badge` at
≥18px only), focus = 2px `hb-focus-ring` + 2px offset (DR-4).
